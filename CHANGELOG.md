## 1.0.0 — 2026-11-10

* **Автооценка CRM — отдельный модуль shef.toolsaicrm 1.0.0** (bx-shef/toolsai#639). Анализ сделок, лидов и смарт-процессов вынесен из shef.toolsai: профили анализа, риск и вердикт модели, поля «AI: …», отметки, дела и комментарии менеджерам и старшим, история риска, скрипты оценки звонков, оценка работы менеджеров, статистика («Анализ записей CRM», «Оценка работы менеджеров»), робот бизнес-процесса «AI: оценить сейчас», промпты анализа по уровням.
  * Нужен shef.toolsai 1.96.0 и выше: модель, лицензию, квоту, журнал расхода (категория «Авто-анализ CRM») и права модуль берёт через публичный API движка; своих лицензии и квоты у него нет.
  * Установка переносит данные из shef.toolsai сама: профили, проверки, историю, правила скриптов звонков, промпты анализа и настройки (`DEAL_*`, `ANALYSIS_*`, `CALLSCRIPT_*`); после сверки в настройках обоих модулей ставится отметка переноса. Поля «AI: …», тип поля и робот БП не пересоздаются. Агентов анализа — ровно по одному на тип записи.
  * Страница `/shef/toolsaicrm/`: «Общие», «Авто-анализ CRM», «Промпты анализа», «Анализ записей CRM», «Оценка работы менеджеров»; права — роли shef.toolsai.
  * Для соседей: событие `shef.toolsaicrm:OnAfterCrmWrite`, REST `shef.toolsaicrm.report.managerscores` и манифест `shef.toolsaicrm.mcp.tools` (область `shef_toolsaicrm`).
  * Справка — пакет `shef.toolsaicrm:guide` («База знаний»), документация `docs/`, лента «Что нового», правила ревью по уровням, навыки репозитория.
