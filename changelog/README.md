# Лента «Что нового»

Записи для страницы `/changelog` посадочной. Файл — `changelog/<ГГГГ-ММ-ДД>-<номер PR>.md`:

```markdown
---
product: crm               # toolsai | assistant | mcp | announce | crm | kb | eval | memory | light | embed
date: 2026-10-22
pr: 313
version: 1.63.7           # если известна; иначе пусто
kind: new                 # new — новое, improved — улучшено, fixed — исправлено; пусто — new
weight: 1                 # 3 — главное выпуска, 2 — заметное, 1 — рядовое; пусто — 1
title: Групповые операции показывают прогресс
shots:                    # что снять на стенде; пусто — запись без картинки
  - name: progress
    url: /shef/toolsaicrm/
    steps: ["выделить 5 строк", "Действия → Оценить запись"]
    crop: ".shef-ai-progress"
---
Запуск оценки на нескольких сделках показывает, сколько сделано, а после перезагрузки продолжается с того же места.
```

- Текст — для руководителя: 1–2 предложения, 20–400 знаков, что умеет продукт и зачем это нужно, в настоящем времени. Без имён классов (`::`, `\`), ссылок «файл:строка», цен, HTML и слов «теперь», «больше нет», «с версии» — это ловит проверка; понятность и тон — ревью.
- Порядок: открыть PR → номер PR → файл записи с этим номером в ту же ветку.
- `product` — продукт этого репозитория; `date` — ГГГГ-ММ-ДД; имя файла совпадает с `date` и `pr`.
- Технический PR (CI, документация, тесты, навыки) записи не несёт; его строка в «Не выпущено» CHANGELOG.md — с пометкой «(лента: нет)».
- `steps` — JSON-список шагов по порядку: текст или CSS-селектор — щёлкнуть; `"правой кнопкой: текст или селектор"` — контекстное меню (ждёт элемент до 90 с); `"ждать: текст"` (до 30 с), `"навести: текст"`, `"прокрутить: 600"`, `"пауза: 1500"`, `"ввести: селектор | текст"` — набрать текст в поле и нажать Enter (вопрос помощнику: `"ввести: .shef-aia-input | Какие сделки без задач?"`, затем `"ждать: Подробнее"`). Шаг — то, что есть на странице (текст элемента или селектор), а не описание действия: «открыть групповой чат» не найдётся — нужен адрес чата в `url` (`/online/?IM_DIALOG=chat314`). Последний из нескольких элементов — `>> nth=-1`: `".bx-im-message-base__body >> nth=-1"`. `crop` — CSS-селектор области кадра (начинается с `#` — в кавычках: `crop: "#main"`), пусто — весь экран 1280×800.
- Картинка записи — `changelog/<ГГГГ-ММ-ДД>-<PR>/<name>.webp` (снимает `./stand.sh shots` в toolsai-stand: `docker/record/shots.mjs`); пока файла нет, запись выходит без картинки.
- Номер PR берётся из `FEED_PR` или `gh pr view`: среди новых записей ветки есть запись этого PR; номер не определён — сверка пропущена с пометкой. Записи за чужие PR (задним числом) идут вместе с записью своего PR или с `FEED_PR=`.
- `kind` и `weight` задают место записи на странице «Что нового» (`site/landing/whatsnew.js`): главное (первая с весом 3), до двух заметных, до восьми рядовых, «Улучшено», «Исправлено», «Прошлые выпуски». Значения проверяет `build.sh --check`: kind — только new, improved, fixed; weight — 1, 2 или 3.
- Проверка — `tools/changelog-feed-check.sh`, её зовёт `build.sh --check`.
