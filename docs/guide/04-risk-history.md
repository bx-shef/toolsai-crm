# История риска

> Последняя сверка: 2026-11-09

## Что и зачем

Одна цифра риска не говорит, что происходит со сделкой во времени: риск
растёт или падает, выполняют ли люди советы AI. Модуль хранит
**каждый анализ** и показывает короткую историю в карточке. Модель тоже
видит прошлые анализы — и может сказать: «три раза подряд советовали
позвонить, никто ничего не отметил».

## Где хранится

Таблица `shef_toolsaicrm_analysis_history` (`Analysis\Model\HistoryTable`) —
одна строка на анализ с обращением к модели, для сделок, лидов и
смарт-процессов:

| Колонка | Что |
|---|---|
| `ENTITY_TYPE_ID`, `ENTITY_ID` | чья запись |
| `CREATED_AT` | когда |
| `RISK` | риск, % |
| `WHY` | почему (коротко, до 255 символов) |
| `ACTION` | что модуль сделал (как колонка «Эскалация») |
| `COST_MICRO` | стоимость запроса, микро-единицы |
| `MARKED` | стояла ли хоть одна отметка к моменту этого анализа |
| `EXTRA` | свои поля ответа из шаблона промпта (JSON) |

Создают установщик и «Проверить и включить» (идемпотентно). Данные
переносятся из shef.toolsai при установке ([Перенос из shef.toolsai](11-migration.md)).
Удаляется вместе с модулем без «Сохранить данные».

**Что значит `MARKED`.** Модуль смотрит отметки «Отработано» и «Риск под
контролем» **до** того, как записать новый анализ. Значит, `MARKED = Y` —
кто-то отреагировал на прошлый совет.

## В карточке

Поле «AI: история» (`UF_SHEF_AI_HISTORY`) — последние 5 анализов по
строке: `04.10.2026 — 80%, отмечено`. Отдельной вкладки нет — поле лежит в
разделе «AI-анализ» вместе с остальными.

## Для модели

В конец сводки — последние 3 анализа (`Analysis\History::toPromptText()`):
дата, риск, были ли отметки, почему. Если 3 анализа подряд без отметок —
строка «Внимание: … рекомендации не выполняются». В шаблоне промпта это
переменная `{история}`.

## Чистка

Агент анализа в начале каждого прогона удаляет записи старше 180 дней
(`History::KEEP_DAYS`, `HistoryTable::cleanup()`).
