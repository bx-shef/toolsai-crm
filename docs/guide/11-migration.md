# Перенос из shef.toolsai

> Последняя сверка: 2026-11-09

## Что и зачем

Автоанализ CRM — профили, проверки, история риска, скрипты звонков, шаблоны
промптов — живёт в отдельном модуле shef.toolsaicrm. Данные портала из shef.toolsai
**переносятся при установке сами**: ничего переписывать и создавать заново не
нужно. Поля «AI: …», тип поля `shef_toolsai_ack` и робот БП «AI: оценить сейчас»
работают как есть: поля не пересоздаются, схемы бизнес-процессов не меняются.

## Что переносится

| Откуда (shef.toolsai) | Куда (shef.toolsaicrm) |
|---|---|
| таблица `shef_toolsai_deal_profile` | `shef_toolsaicrm_deal_profile` |
| `shef_toolsai_entity_check` | `shef_toolsaicrm_entity_check` |
| `shef_toolsai_analysis_history` | `shef_toolsaicrm_analysis_history` |
| `shef_toolsai_call_script_rule` | `shef_toolsaicrm_call_script_rule` |
| строки `analysis.%` таблицы `shef_toolsai_prompt` | `shef_toolsaicrm_prompt` |
| настройки `DEAL_enabled`, `DEAL_maxperrun`, `DEAL_interval`, `DEAL_crmevents` | под теми кодами в настройках shef.toolsaicrm |
| `ANALYSIS_interval_<тип>`, `ANALYSIS_maxperrun_<тип>` | под теми кодами |
| `CALLSCRIPT_mode`, `CALLSCRIPT_fallback` | под теми кодами |

Остаются на месте и работают без изменений: поля `UF_SHEF_AI_*` в сделках, лидах и
смарт-процессах, тип поля, заглушка робота (её пишет shef.toolsaicrm).

## Как идёт перенос

Перенос — часть установки модуля (`Main\Migration`, его запускает
`Main\Setup` из установщика и кнопка «Проверить и включить»):

1. **Остановка старого.** Агенты анализа shef.toolsai (`AnalysisAgent`,
   `DealHealthAgent`) и его подписки на события полей и скриптов звонков
   (`main:OnUserTypeBuildList`, `main:onGetPublicEdit`, `crm:OnBeforeCrmDealUpdate`,
   `crm:OnBeforeCrmLeadUpdate`, `crm:OnBeforeCrmDealAdd`, `crm:onCrmDynamicItemAdd`,
   `crm:OnBeforeCrmActivityAdd`) снимаются: их держит новый модуль. Идёт старый
   прогон — установщик ждёт его до 30 секунд; не остановилось — данные не
   копируются, отметок нет.
2. **Копия.** Строки копируются пачками с теми же `ID` (промпты — по `CODE`).
   Повтор добирает недостающее и ничего не затирает. Когда перенос уже отмечен
   (шаг 4), строки не копируются повторно: удалённое в новом модуле не
   возвращается. Настройки копируются, только
   если в новом модуле значения ещё нет: то, что администратор поправил уже
   здесь, не перезаписывается.
3. **Сверка.** По каждой таблице: строк источника без пары в приёмнике нет и
   совпало содержимое общих столбцов (для промптов пара — по `CODE`); строки с теми же
   ключами, но другими значениями — конфликт. У настроек — каждая на месте.
4. **Отметки.** Сверка сошлась — в настройках shef.toolsaicrm записывается
   `SYS_migrated_from_toolsai`, а в настройках shef.toolsai — `SYS_crm_moved` («время|числа»).
   Только по этой отметке shef.toolsai убирает у себя старые таблицы, настройки и
   строки промптов `analysis.%`.
5. **Агенты.** Для каждого типа с включённым профилем заводится агент
   `\Shef\ToolsAiCrm\Agent\AnalysisAgent::run(<entityTypeId>);` — по одному на тип.
   Первый запуск — через интервал агента. Агенты анализа, подписки поля «AI: …» и
   робот БП включаются, когда перенос отмечен или переносить нечего; до этого их нет.

Не сошлось — ничего не помечается, старое остаётся нетронутым, а отчёт установки
называет, что не так. Установка при этом не падает: перенос повторяется сам каждые
10 минут, его можно повторить кнопкой «Проверить и включить». Данные shef.toolsai не удаляются, пока нет отметки.

## Что видит администратор

* Установлен shef.toolsaicrm — анализ работает без перерыва: профили, промпты,
  история, отметки на карточках, робот БП.
* shef.toolsaicrm не установлен, а данные анализа в shef.toolsai есть, — вместо
  анализа администратору приходит разовое уведомление и плитка «Установить».
  Анализ не работает, пока модуль не установлен; поля и история в карточках остаются.
* Устаревшие агенты и подписки shef.toolsai не мешают: их гасят оба модуля.

## Сверка после переноса

1. «Авто-анализ CRM»: профили на месте, агенты — по одному на тип.
2. «Промпты анализа»: свои шаблоны на месте.
3. «Анализ записей CRM»: цифры за прошлые периоды совпадают.
4. Карточка сделки: поля «AI: …» заполнены, кнопки работают.
5. «Проверить и включить» — строки отчёта без ошибок.
