# Карта модуля shef.toolsaicrm

> Последняя сверка: 2026-11-14 — по коду 1.0.1 (выпущен 14.11; 1.0.0 — 11.11)

## Цель

Автооценка CRM отдельным модулем: AI оценивает сделки, лиды и смарт-процессы, ставит дела
менеджерам и старшим, оценивает работу менеджеров. Вынесен из `shef.toolsai`
(bx-shef/toolsai#639): код, таблицы, агенты и страницы анализа живут здесь; данные при установке
переносятся сами, в shef.toolsai то же выпуском удаляется.

## Что в работе

* Проверка на портале с данными анализа: перенос, поля и кнопки в карточке, робот БП, агенты по типам.

## Код

* `lib/analysis/` — прогон (`Runner`), кандидаты, типы записей, поля «AI: …», запись в CRM, история, промпты по уровням.
* `lib/deal/` — сводка для модели, анализатор, шкала, эскалация, профили, поля-кнопки, тип клиента.
* `lib/callscript/` — правила скриптов оценки звонков.
* `lib/chat/`, `lib/email/` — чтение чатов и писем для сводки.
* `lib/stats/` — отчёты «Анализ записей CRM» и «Оценка работы менеджеров».
* `lib/core/`, `lib/container.php` — шов к shef.toolsai (модель, расход, квота, лицензия).
* `lib/main/` — перенос, «Проверить и включить», доведение, заглушки страниц, константы.
* `lib/settings/`, `settings/`, `lib/ui/` — страница модуля, «?» и справка.
* `lib/internals/`, `lib/integration/`, `lib/rest/` — события shef.toolsai и shef.toolsaikb, REST, MCP.
* `activities/analyze/` — робот БП; `install/` — установщик и раскладка из git; `kb/guide` — справка.
* `tests/` — тесты на заглушках, запуск `./build.sh --check`.

## Линейка AI: зависимости и связь событиями

| модуль | зависимость |
|---|---|
| `shef.toolsai` | обязательна, 1.96.0+: модель, расход, квота, лицензия, права (публичный API) |
| `shef.toolsaikb` | по желанию: статьи справки (`OnKbSourcesCollect`) |

| событие | кто шлёт | что делает этот модуль |
|---|---|---|
| `shef.toolsai:OnRocketCardsCollect` | toolsai | отвечает карточками раздела |
| `shef.toolsai:OnViewAnalyzeRecord`, `OnViewAnalysisState` | toolsai | запуск анализа и состояние для вида «AI» |
| `shef.toolsaikb:OnKbSourcesCollect` | kb | отвечает пакетом `shef.toolsaicrm:guide` |
| `shef.toolsaicrm:OnAfterCrmWrite` | этот модуль | шлёт соседям после записи в CRM |

## Открытые вопросы
